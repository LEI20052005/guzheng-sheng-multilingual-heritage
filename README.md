# 声生不息 · 古筝与笙的多语种数字传承计划

> 梳理民乐源流，留存传世音律 —— 一个聚焦 **古筝** 与 **笙** 两大中国传统乐器的数字资料库网站。



## ✨ 功能板块

| 板块 | 说明 |
| --- | --- |
|  首页 | 项目简介与快速导航 |
|  乐器资料库 | 古筝 / 笙的历史、形制、音色、名家与经典曲目（点击卡片查看详情） |
|  经典曲目库 | 《高山流水》《广陵散》《冬猎》《晋调》等传世名曲赏析与在线试听 |
|  视频展厅 | 高清演奏视频（古筝《渔舟唱晚》、笙《凤凰展翅》） |
|  建模展示 | 基于 Three.js 的乐器 3D 模型交互展示（古筝 / 笙，可旋转缩放） |
|  互动答题 | 「丝竹寻音」知识问答，8 题一轮，中英双语，称号挑战 |
|  多语言 | 全站中文 / 英文一键切换 |
|  项目介绍 | 项目背景与建设目标 |

## ⚠️ 项目资源取舍说明
本项目为纯静态网页作品，两处网站业务素材暂未纳入线上仓库，属于**主动工程取舍**，并非功能缺失：

1. **古筝 3D 模型**：源文件为 FBX 格式，贴图复杂、面数较高。
2. **两支民乐演奏视频素材（网站页面内播放素材）**：高清视频文件体积巨大，不适合放进 Git 代码仓库（会造成仓库臃肿、Git 提交 / 拉取极慢，GitHub Pages 部署包超限）。网页预留视频播放组件与页面布局逻辑，本地预览时，将视频放入`assets/videos`目录即可正常播放。


## 👨‍💻 个人项目职责

本项目个人承担**全栈前端 + 3D 可视化工程**工作：

- 静态资源管理，音频 / 图片 / 视频资源路径规划；



## 🚀 本地预览

网站为**纯静态页面**，无需安装任何依赖：

- **直接双击 `index.html`** 即可在浏览器中打开；
- 更推荐用本地服务器打开（部分浏览器对 `file://` 协议有安全限制）：

```bash
# 任选其一
python -m http.server 8000        # Python
npx serve .                       # Node.js
```

然后访问 <http://localhost:8000>。

## 🌐 部署到 GitHub Pages

1. 将本仓库推送到 GitHub；
2. 进入仓库 **Settings → Pages**；
3. Source 选择 `main` 分支 / 根目录，保存；
4. 稍候片刻即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
